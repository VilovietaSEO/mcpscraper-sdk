## Existing aggregate validation limitations

`npm run validate-contracts` is not a passing candidate gate. Its Assistant owner OpenAPI lint reports **73 errors and five warnings**. The exact unchanged contract from baseline `edb2e0c` reproduces those counts with the same linter; this release does not modify that contract. The aggregate command also requires a direct Memory manifest or credential and compares the candidate with the still-unreleased hosted contract. Source-manifest parity and generated-surface checks above are separate passing candidate checks, not a claim of hosted release parity.
